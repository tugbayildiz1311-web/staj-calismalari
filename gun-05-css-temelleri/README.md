# Gün 5 - CSS Temelleri

## Margin ve Padding Farkı

`margin`, bir elemanın dışındaki boşluğu ayarlar ve elemanla çevresindeki diğer elemanların arasını açar. `padding` ise elemanın içeriği ile kenarlığı arasındaki boşluğu belirler.

Bu çalışmada `.container` elemanına verilen `margin: 40px auto` değeri kartın üst ve altında boşluk oluşturup yatay olarak ortalanmasını sağladı. `padding: 24px` değeri ise kartın içindeki form ve tabloyu kartın kenarlarından uzaklaştırdı.
