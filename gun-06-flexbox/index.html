Temel Web Teknolojileri

HTML

HTML, bir web sayfasının temel yapısını oluşturur ve başlık, paragraf, görsel ve bağlantı gibi içerikleri tanımlar.

CSS

CSS, HTML ile oluşturulan içeriklerin renk, yazı tipi, boyut, boşluk ve yerleşim gibi görsel özelliklerini düzenler.

JavaScript

JavaScript, web sayfalarına etkileşim ve dinamik davranış kazandırır; butonların çalışması ve içeriğin kullanıcı işlemlerine göre değişmesi gibi görevleri gerçekleştirir.

Bu sayfa Flexbox özelliklerini uygulamak amacıyla hazırlanmıştır.
