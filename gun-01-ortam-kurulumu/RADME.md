# GÜN 1 - GELİŞTİRME ORTAMI KURULUMU
Bu çalışma, stajımın ilk gününde temel web geliştirme araçlarını tanımak ve kullanım amaçlarını öğrenmek amacıyla yazılmıştır.


## Kullanılan Araçlar

### VS Code
VS Code, kod yazmak ve proje dosyalarını düzenlemek için kullanılan bir kod editörüdür.

### Tarayıcı ve DevTools
Tarayıcı, hazırlanan web sayfasını görüntülemek içn kullanılır. DevTools ise HTML yapısını, CSS kurallarını ve JavaScript çıktılarını incelemeye yardımcı olur.

### Git
Git, proje dosyalarındaki değişiklikleri takip etmek ve sürüm geçmişi oluşturmak için kullanılır. 

### GitHub
GitHub, Git ile takip edilen projeleri internet üzerinde saklamak ve paylaşmak için kullanılan bir platformdur.
