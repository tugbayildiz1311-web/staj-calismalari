## Temel Kavramlar

### Etiket
Etiket, HTML belgesindeki bir içeriğin türünü ve görevini belirtmek için kullanılan işarettir.

### Attribute
Attribute, bir HTML elementine ek bilgi veya özellik kazandıran ifadedir.

### Element
Element, açılış etiketi, içerik, varsa attribute'lar ve kapanış etiketinin tamamından oluşur.


## Kullandığım Beş HTML Etiketi

1. `<h1>` : Sayfanın ana başlığını oluşturmak için kullandım. Yalnızca 1 ana başlık kullandım.
2. `<P>` : Kendimi tanıttığım metinleri ayrı paragraflar halinde yazmak için kullandım.
3. `<ul>` : Bildiğim teknolojileri, sırasız liste halinde yazmak için kullandım. 
4. `<img>` : Çalışma ortamıyla ilgili bir görseli sayfaya eklemek için kullandım. Görselin yolunu 'src', açıklamasını ise 'alt' attribute'u ile belirttim.
5. `<a>` : Sayfada GitHub profilime yönlendiren bir bağlantı oluşturmak için kullandım.
